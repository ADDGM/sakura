# Agent Note: Live2D 部署后的边界与连续收起验证

Status: implemented

## Problem

播放器收起残余40px的问题已修复，但此前默认桌面宽度的两轮验收不能证明861px桌面边界和连续操作同样稳定。用户要求继续检查现有基础功能。

## Decision

补验直接访问测试站的已部署脚本，在860、861、900、1280px各创建独立浏览器上下文。860px检查隐藏及零模型请求；其他宽度各连续展开收起5次，等待动画结束，断言展开避让、收起恢复0px和保存位置未被写入。不开启后台配置修改，不覆盖服务器，不注入本地修复脚本。

## Existing record audit

创建时检索Live2D、Semgrep、日志及Cubism没有命中，不存在可复用的模块笔记。旧收起修复报告与本篇部分重叠，其根因、26项浏览器/19项Node和构建75部署证据现已归并到[浮层位置笔记](../bug-fix/2026-10-07-live2d-player-layout.md)，旧报告按用户授权退役；本笔记继续负责多宽度重复交互。

后续历史提炼形成[基础接入契约](../architecture/2026-10-07-live2d-integration.md)与[浮层位置契约](../bug-fix/2026-10-07-live2d-player-layout.md)，两者与本篇部分重叠，负责运行时行为，本篇继续负责验证策略与覆盖边界。

后续提炼的[兼容性证据](2026-10-07-compatibility-evidence.md)及[质量工作流](../process/2026-10-07-quality-workflow-boundary.md)与本篇部分重叠，分别说明通用证据层级与扫描配置；本篇保留Live2D实站结果和未关闭告警的具体范围。

## Alternatives considered

- 只重跑本地26项夹具：覆盖更全面且稳定，但不能证明服务器实际脚本在各宽度下运行，因此沿用已有通过结果，本次补做直接实站检查。
- 沿用1280px两轮部署结果：已有有效证据且无需新增运行，但不足以覆盖桌面阈值与重复操作；新增三组桌面宽度各五轮，限制测试规模。

## Consequences

直接实站测试可发现部署与整站样式问题，但受网络、音频资源与浏览器计时影响。每轮等待动画结束，不用强制重算或重置掩盖残余位置。本次没有重跑Tia后台切换、PJAX、触摸与长歌词所有组合，不将此前通过结果冒称为本轮测试。

## Runtime audit boundary

另对Semgrep告警28作只读追查：压缩运行时的`n._$li`存在17处显式点调用，大部分使用固定格式字符串；动态路径包含动作队列捕获异常、createCanvas错误值、版本数字及iPad设备信息错误分支。`n._$li`只接收两个参数，后两类动态字符串调用未传第二实参。当前未证明攻击者可控制第二格式参数或造成代码执行；告警仍保持open，不标为已修复或误报。CodeGraph未索引此混淆符号，使用定点文本检查，未完成所有动态属性访问的数据流证明。没有为此新增或修改第三方运行时代码。
