# Agent Note: Live2D 配置使用独立看板娘标签

Status: implemented

## Problem

本次改动前，Live2D的总开关、模型、远程换装开关及接口地址夹在options.php的Others分组内，与图片加载、剪贴板和邮件等配置混排。用户认可独立「看板娘」标签。

## Decision

在现有主题设置页标签栏末尾追加「看板娘」，使用稳定heading id `live2d`。将四个完整选项定义整体移动到此分组：`live2d_s`、`live2d_m`、`live2d_b`、`live2d_i`。保留其配置键、默认值、字段类型和保存入口；无需迁移数据库或修改前台加载逻辑。

组内依次展示总开关、Tia/Pio模型、远程换装开关和接口地址。使用现有info字段提供简短说明：屏幕宽度至少861px时加载，可用拖动手柄调整位置，并通过重置按钮恢复。远程换装继续使用已有说明，不新增联动隐藏、独立后台菜单、服装选择器或运行时升级选项。

新增标签和说明同步POT、简繁中文、英文、日文PO/MO。标签中文显示「看板娘」，不修改前台现有「Live2D 看板娘」文案。复用现有Options Framework的heading和info，不引入新的界面组件或依赖。

## Alternatives considered

- 在「其他」前插入新标签：分类顺序更符合「其他」收尾的惯例，但框架按遍历顺序生成options-group编号，可能让已记住的标签位置改变。选择追加末尾，保留现有标签编号。
- 只在「其他」里增加小标题：改动更少，但仍需进入不相关的标签才能找到配置，不符合用户已认可的独立入口。
- 新增WordPress后台菜单页：入口更突出，但四个设置不足以支持独立页面的维护成本；保留现有保存和权限机制。
