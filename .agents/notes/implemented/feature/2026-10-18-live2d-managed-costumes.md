# Agent Note: 按模型管理 CDN 与本站服装库

Status: implemented

## Problem

维护者已完成自定义五套服装清单验收，但完整资源仍需反复手动上传和填写地址，根级复制来的目录也没有表达模型兼容性。2026-10-18维护者选择“CDN 默认＋可选下载本站”，并授权规范化现有仓库路径。此决定接管此前下载功能只讨论的边界。

## Decision

现有107张PNG按字节不变迁移到 `live2d/costumes/pio/textures/`，文件名使用小写ASCII与短横线。受信清单包含模型指纹、相对路径、大小和SHA-256，排除三份与Pio内置纹理相同的内容，实际扩展104套。生成器支持 `--check`，模型指纹必须与已验证版本一致。PNG留在仓库供CDN访问，安装包仅包含轻量清单和代码。

来源统一为 jsDelivr、本站、仅内置、自定义清单、旧PNG接口，显式选择互斥。没有新设置时保留旧接口或自定义清单选择，其余默认CDN；模型切换自动关联兼容库，Tia没有扩展时继续内置。CDN绑定安装包源码提交或已配置固定引用；无有效来源时不拼接不存在的地址。

后台下载由用户点击触发，使用权限与nonce检查，仅按主题清单读取固定CDN地址。每张下载完后验证大小、SHA-256和PNG；可恢复已验证进度，最后完整核验成功才标记可用。目录位于上传根下 `sakura-live2d/managed/<model>/<fingerprint>/`，与自定义目录隔离，版本隔离且不随主题替换清理。下载完成后选择“本站”，提示保存，不能自动覆盖其他未保存设置。前台仍先加载内置纹理，候选只按需读取单张PNG，保留现有换装与GPU释放流程。

维护者随后明确要求分片、文件内续传、失败清除和覆盖重下：每次读取256KiB的HTTP Range，校验206的Content-Range及字节数，最终整张PNG校验成功才安装；服务器忽略Range时允许有界的完整文件200响应。部分文件保留在受控目录，页面关闭后可恢复。覆盖下载保存已完成项目状态，原可用文件在新文件通过校验前保留；清除只作用于当前托管版本的未完成内容，已有完整启用库与自定义目录保留。

源码归档必须保留完整扩展PNG，主题CI和Release仅在解包到安装载荷时排除 `sakura/live2d/costumes/*/textures`。构建88曾用全局export-ignore排除这些图片，公开后的jsDelivr文件清单也缺少107PNG；其中一张在GitHub存在却持续404，整库下载无法完成。因此小主题包的排除规则由两条安装包流水线持有，不再影响CDN使用的源码归档。回归同时验证源码归档包含107PNG、两条流水线的tar过滤均保留轻量清单及内置模型而排除扩展图片。

CDN链接中的固定标签和完整提交SHA都可固定资源版本，默认仍复用安装包来源SHA，避免主题清单与图片版本错配；标签必须包含新目录，不能用旧标签代替资源发布。2026-10-18核对[jsDelivr官方说明](https://github.com/jsdelivr/jsdelivr#restrictions)，默认包上限为150MB、GitHub单文件上限20MB；这些是服务商当前规则，后续发布仍需复核。源码归档包含图片，不要求站点安装此归档；CI与Release主题ZIP继续保持精简。

## Alternatives considered

- 继续手动静态清单：无服务端下载代码且存储自由，但维护者已明确要求模型联动和可选下载，保留为高级入口。
- 将全量PNG装入主题ZIP：部署最直接，却增加约48MiB压缩体积并重复传输，不满足小安装包目标。
- 只提供CDN：实现最小，但无法满足本站托管选择；保留按需CDN为默认，后台下载为主动操作。
- 一次请求下载整个ZIP：请求次数少，但占用长请求并引入解压和整包重试；逐张验证更适合普通PHP主机。
- 仅将SHA链接换成版本标签：标签易读且能固定版本，但同一提交的归档排除规则不随名称变化，不能修复已缺失的CDN资源；保留固定引用支持，修正安装包排除的位置。

## Consequences

CDN可用性、服务器出站网络和磁盘空间仍是外部条件；失败继续保留内置外观。Range与逐张核验降低重试损失，但增加请求次数；覆盖期间同时保留旧PNG和该文件分片，磁盘需留出余量。每个版本独立目录占用磁盘，主题不自动删除历史资源或用户目录。读取状态会核验本地文件，前台只读取完成标记，外部删改仍由换装失败和下一次下载检查发现。素材来源证据沿用原笔记，文件同源不代表新增授权。全图片源码ZIP体积增加，站点应安装CI或Release生成的精简主题ZIP。功能提交已获维护者批准并推送；归档修正尚未提交，真实新CDN、目标主机下载和安装验收保持独立交接，不自动部署或创建发布标签。
