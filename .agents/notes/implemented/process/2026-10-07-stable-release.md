# Agent Note: Live2D 基础功能正式发布

Status: implemented

## Problem

用户要求将已验收的Live2D基础功能正式发布。此前正式版v3.6.1对应99f3c11，develop的6b10d85包含其后10笔提交；构建78和后台、前台补验已完成，需要将这些变更交付为新的正式Release。

## Decision

正式版本采用用户确认的v3.7.0，以次版本号表达新增可选Live2D基础功能与独立设置标签。发布准备仅调整style.css源码基准，不扩展功能。先提交版本准备并推送develop，等待该提交的兼容性与质量CI成功；再对同一SHA创建新标签并推送，由现有Release工作流生成安装包、校验文件与中文更新记录。该顺序只说明发布规则，后续提交、推送和标签发布仍需各自获得授权。

推送标签会直接创建公开正式Release并触发既有TG发布通知，不是草稿操作。构建78的成功不能代替版本提交CI，Release工作流自身不运行完整WordPress矩阵。发布后核对标签SHA、工作流、资产下载、校验和、包版本与build-info；测试站仍由用户部署。

## Alternatives considered

- v3.6.2：可以表示维护发布，但难以反映相对正式版新增的完整可选模块，推荐v3.7.0。
- 直接在现有6b10d85上推v3.7.0标签：无需版本提交，但源码Version仍为3.6.1，现有发布基准检查会拒绝，不能采用。
- 重新发布v3.6.1：无需新版本号，但覆盖已发布资产会混淆版本身份和用户更新判断，采用全新标签。
